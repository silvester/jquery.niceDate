jQuery plugin · v0.2 · MIT

Dates people can actually read

niceDate turns 12.12.2012 15:30 into "3 days ago" and keeps it fresh. Multilingual, tiny, zero configuration.

Usage

		
Include jQuery, the plugin and optionally a language file.

		
<script src="jquery.js"></script>
<script src="jquery.niceDate.js"></script>
<script src="i18n/sl.js"></script> <!-- optional -->

<span class="date">12.12.2012 15:30</span>

<script>
  $('.date').niceDate();

  // refresh manually
  $('.date').each(function () {
    $(this).data('plugin_niceDate').update();
  });
</script>

	


	

		
Options

		

			

				
OptionDefaultDescription

				
					
nowDateObjectnullReference "now". Defaults to the current time.

					
makeTimestampfunctionTakes the element text and returns a JS Date, or false to leave the element untouched.

					
pattern/([0-3]?[0-9])\.([01]?[0-9])\.(\d{4})\s?(\d{2})?:?(\d{2})?$/How to parse the date text.

					
patternOrder[3, 2, 1, 4, 5]Position of year, month, day, hour, minute in the pattern.

					
dayOnlyfalseShow only days, never hours or minutes.

					
hoverShowtrueShow the original date on hover.

					
autoUpdateInterval60000Refresh interval in ms. 0 disables updates.
